# Hotel Booking Data Analysis | MySQL

## Project Overview

Analyzed 5,000 hotel booking records using MySQL to understand
booking patterns, cancellations, revenue performance, customer
segments, hotel performance, country performance, and monthly trends.

## Tools Used

* MySQL
* SQL
* MySQL Workbench

## Dataset

* Records: 5,000
* Table: hotel\_bookings
* Database: hotel\_analysis

## Key Analysis Areas

* Booking overview
* Cancellation analysis
* Revenue analysis
* Market segment analysis
* Country analysis
* Monthly revenue trends
* Hotel performance
* Room type analysis
* Meal analysis
* Advanced SQL analysis using CTEs and RANK()

## Key KPIs

* Total Bookings: 5,000
* Total Booking Value: 200,124,609.43
* Realized Revenue: 52,409,967.32
* Revenue Realization Rate: 26.19%

## SQL Concepts Used

* SELECT
* WHERE
* GROUP BY
* ORDER BY
* Aggregate Functions
* CASE WHEN
* CTEs
* Window Functions
* RANK()
* Date Functions





\## Key Insights



\- City Hotel accounted for 66.54% of realized revenue.

\- Online bookings contributed 48.62% of realized revenue.

\- Overall cancellation rate was approximately 19.26%.

\- Germany generated the highest realized revenue among the analyzed countries.

\- September 2024 recorded the highest monthly realized revenue.

\- The overall revenue realization rate was 26.19%.
